# Тесты

```bash
python scripts/check.py      # ruff + pytest
pytest -q                    # только тесты
```

| Файл | Что проверяет |
|---|---|
| [`fixtures/`](fixtures/) | 10 строк заказов (одна — точный дубль) и 2 возврата; каждое значение витрин можно посчитать вручную, таблица в [`conftest.py`](conftest.py) |
| [`test_etl.py`](test_etl.py) | дубли удаляются, битые даты (`00:00.0`) отклоняются, даты dd-mm-yyyy читаются, возвраты связываются с учётом `United States` → `US`, xlsx = csv, вход не мутируется, Parquet не пишется при провале проверок |
| [`test_quality.py`](test_quality.py) | каждая проверка качества срабатывает на внесённом дефекте |
| [`test_marts.py`](test_marts.py) | точные значения всех 7 витрин, доверительный интервал маржи, рост год к году без ложных сравнений, сходимость сумм между витринами |
| [`test_stats.py`](test_stats.py) | модель восстанавливает известные эффекты скидок; стоимость доставки не входит в модель; t-тест отдаёт разницу в $ с интервалом |
| [`test_pipeline.py`](test_pipeline.py) | полный прогон на закоммиченном Parquet совпадает с закоммиченными `outputs/`; итоги датасета; плохой Parquet останавливает пайплайн |
| [`test_dashboard.py`](test_dashboard.py) | дашборд отрисовывается, KPI следуют фильтрам, пустые срезы не падают |
| [`test_postgres.py`](test_postgres.py) | повторная загрузка в настоящий PostgreSQL (pgserver) сохраняет типы, ограничения и view |

Все тесты пишут только во временные каталоги pytest.
